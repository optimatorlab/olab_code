Set up local YOLO models
Install the optional dependency in the environment that runs this page: pip install -e 'packages/olab_camera[yolo]'.
Download model files yourself, then place them under the configured model root (by default ~/Projects/olab_models). Refresh this page to discover them. The playground never downloads model weights.
TaskSuggested small local model
Object detectionyolo11n.pt
Segmentationyolo11n-seg.pt
Poseyolo11n-pose.pt
Classificationyolo11n-cls.pt
Oriented bounding boxesyolo11n-obb.pt
Get task-compatible weights from the official Ultralytics model documentation.

    
Python equivalent

    
Provision local YOLO models
Before opening the browser UI, activate the olab_code virtual environment, change to the configured model root (normally ~/Projects/olab_models), then explicitly instantiate only the models you want:
cd ~/Projects/olab_models
python
>>> from ultralytics import YOLO
>>> YOLO("yolo11n.pt")
>>> YOLO("yolo11n-seg.pt")
>>> YOLO("yolo11n-cls.pt")
>>> YOLO("yolo11n-pose.pt")
>>> YOLO("yolo11n-obb.pt")
>>> YOLO("yolo26n.pt")
>>> YOLO("yolo26n-seg.pt")
>>> YOLO("yolo26n-cls.pt")
>>> YOLO("yolo26n-pose.pt")
>>> YOLO("yolo26n-obb.pt")
These are the YOLO11/YOLO26 small detect, segment, classify, pose, and OBB filenames. Track uses the same plain detect checkpoint as detect; there is no -track file family. The browser only lists existing compatible files and never downloads a model.
If installing YOLO support replaces the contrib OpenCV build, restore CSRT tracker support:
python -m pip uninstall -y opencv-python opencv-contrib-python
python -m pip install "opencv-contrib-python>=4.10.0"
python -c "import cv2; print(cv2.__version__, hasattr(cv2, 'TrackerCSRT_create'))"
